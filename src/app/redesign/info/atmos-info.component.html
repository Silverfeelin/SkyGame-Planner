info About

Sky Planner is a fan-made companion website for tracking items and progress in Sky: Children of the Light, a game by thatgamecompany.

Sky Planner is non-commercial, is not affiliated with thatgamecompany and is made available for informational purposes.

share Sharing

You are free to share any page by copying the URL from the address bar or using the share button in your browser.

Although appreciated, it is not required to credit me (Silverfeelin) when sharing the website. I feel like it'd be slightly dishonest to the other people that have contributed directly or indirectly by only crediting me. For the people that want to know more about the site, this page exists.

description License

Source code is publicly available on GitHub under the MIT License.

dns Hosting

Sky Planner is hosted using Cloudflare Pages. Cloudflare Web Analytics is enabled and captures anonymous data without tracking you. This allows for insights such as the amount of page visits and the distribution between desktop and mobile visits to help prioritize development.
